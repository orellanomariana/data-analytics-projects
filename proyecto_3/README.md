# Proyecto 3: Análisis de Obesidad 🏋️‍♀️🍏

Este proyecto tiene como objetivo analizar el nivel de obesidad en diferentes grupos de población, considerando variables como sexo, edad, hábitos alimenticios y actividad física.
Utilizamos visualizaciones y análisis de datos para obtener insights que ayuden a comprender mejor los factores asociados con la obesidad y cómo prevenirla.

## Archivos 📂

- `proyecto_3.pbix`: Archivo de Power BI con las visualizaciones interactivas que presentan el análisis de los datos relacionados con la obesidad.
- `proyecto_3.pdf`: Informe en formato PDF que describe el análisis y los resultados del proyecto, así como las conclusiones y recomendaciones sobre hábitos saludables.

## Descripción del Proyecto 📊

El análisis de obesidad en este proyecto busca responder a preguntas clave como:
- ¿Cómo afecta el sexo y la edad en los niveles de obesidad? 🤔
- ¿Qué relación existe entre hábitos alimenticios, actividad física y obesidad? 🍔🏃‍♂️
- ¿Cuáles son las recomendaciones para mejorar los hábitos y prevenir la obesidad en la población? 💡

Las visualizaciones y el análisis están diseñados para ayudar a las personas a entender cómo la obesidad puede ser gestionada y superada mediante cambios en el estilo de vida. 

## Objetivos 🎯

- Analizar la relación entre obesidad, sexo y edad.
- Considerar los antecedentes familiares
- Evaluar la influencia de hábitos alimenticios y actividad física en el índice de obesidad.
- Generar recomendaciones para la promoción de hábitos saludables y la prevención de la obesidad.


## Herramientas Utilizadas 🛠️
